Add an opt-in `display="flat"` mode that renders options as a vertical list without the wheel's 3D rotation or edge-fade mask. Flat mode defaults to five visible rows; `visibleCount` controls the row count and `optionItemHeight` controls each row's height. It supports the existing scrolling, dragging, keyboard navigation, disabled options, and infinite looping behavior. The default wheel display and label DOM structure remain unchanged.
